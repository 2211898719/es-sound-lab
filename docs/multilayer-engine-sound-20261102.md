# 独立多层合成声浪（0.3.34 / code40）

## 范围与使用

参考EV Engine公开前端可见的多层音色/虚拟动力思路，重新编写Android实现；没有移植网站源码、录音、账户数据或服务，也不请求该网站。参考证据见`evengine-reference-20261102.md`。功能是本App生成的虚拟声浪，不替换原厂ASD/AVAS，不承诺音色与网站或真实V8/V10相同。

覆盖安装后进入模拟声浪详情，主动打开“使用多层合成”，可选V8低沉巡航、V10高转运动、未来电感涡流。自动声浪开关保持原值，新安装默认关闭；改变合成模式不自动开启它。先安全驻车使用虚拟油门视听，确认后再启用D挡实车播放。保留自定义循环音源，关闭合成模式即可切回，文件/预设/主音量不删除、不覆盖。

## 模块

- `EngineTuning`：三种风格、声调75–125%、力度0–100%、换挡运动倾向0–100%；合成源描述为`synth:1:style:tone:intensity`。换挡倾向只属于动力模型，不用于音源缓存键。
- `EnginePowertrain`：独立虚拟六挡，传动比3.8/2.5/1.78/1.34/1.03/0.79、主减速比3.4、轮胎周长2.3m。这些是合成参数，不是本车真实规格。依据车速推导接合转速，起步滑差、至少1.1秒换挡保持、动力升挡/降挡迟滞，400ms升挡卸载、480ms降挡补油；未来音色不做换挡。
- `EngineSynth`：每种风格7层（怠速，低/中/高转驱动与收油）。自行生成周期燃烧脉冲、排气共鸣、谐波与带限噪声，整发动机周期长度、去直流和RMS归一化；V8用不均匀脉冲权重，V10用不同缸数/共鸣，未来音色为谐波涡流。
- `EngineRenderer`：原循环渲染与合成渲染共用目标/输出接口。`PcmEnginePlayer`在工作线程准备音源并输出48kHz立体声PCM，其他音效和锁声播放器路径不变。

驱动/收油按有符号负载等功率混合，各转速层按对数RPM交叉混合；45ms逐采样平滑，周期对齐的随机再分粒与100ms交叉过渡，动态低通、轻饱和与峰值限制。每种风格缓存约1.5MiB PCM层，最多3种，不在音频循环中解码/IO。试听60ms起音、160ms收尾、100ms静音尾巴，排空再释放；安全取消仍立即pause/flush，不用尾音延长过期事件。

声调乘数只改变听感，不改虚拟模型RPM。力度影响饱和、输出强度和负载亮度。换挡倾向影响巡航/动力升挡门限。原速度→音高曲线在合成模式不参与RPM生成，原速度→音量/加速→增强曲线及主音量继续参与。改合成配置/车型会先停止试听或演示，清空实车拟合窗口；重新积累新鲜样本才允许继续。

## 输入与局限

实车只输入ICC有效车速和本App拟合加速度，虚拟油门由`(加速度+简化阻力)/可用加速度`限幅估计。可用加速度依用户马力/零百近似生成；无实测质量、坡度、风阻、真实油门、发动机RPM或变速箱。电动车匀速上坡等情况无法仅由车速正确区分负载，ICC更新和平滑也会带来响应延迟。不能称为真实动力测量。

驻车演示使用用户虚拟油门，仍采用原有80–800匹/3–18秒、≤60秒/≤200km/h边界，不污染ICC状态。真实模式仍须新鲜ICC D挡和至少2个有效速度样本覆盖200ms，样本最长2.5秒、速度>1km/h；P/N/R、未知、过期、停止、校准、喊话与焦点丢失即停止。后台/离页/页面心跳断开停止演示，不自动恢复失败播放。不添加权限、唤醒锁、root或车辆控制。

中控锁及usage2007车外路由未改。此版不能解决熄火后系统拒绝焦点的问题。

## 导出与验证

`engineSimulation`导出当前mode、合成配置、渲染参数与`powertrain`。模型包含虚拟RPM、虚拟gear、signedLoad、estimatedThrottle、换挡方向及`virtual=true`、`actualPedalMeasurement=false`、`actualGearMeasurement=false`。演示模型也在`demo.powertrain`；不得把这些字段当实车挡位/油门。

新增测试覆盖升级数据保留、7层有限/周期/归一化、取消、升降挡/卸载/补油、防频繁换挡、无效输入、未来连续变调、试听首尾、分块一致性、负载音色差异、真实新鲜度/焦点/校准、配置切换与旧回调隔离、缺失旧文件时合成试听、音量0、界面持久化/深浅色及工作线程取消/写失败。

测试生成18秒桌面样音`dist/audio-check/engine-v8-drive.wav`、`engine-v10-drive.wav`、`engine-future-drive.wav`，为同一280匹/7秒虚拟加速后收油，不是网站资源。自动化检查不能代替目标车机欠载、听感及物理扬声器实测；首次请低音量、驻车试听，行车由乘员操作。

发布构建通过145项核心检查及536项Android/Robolectric测试；深浅色/窄屏截图已检查。三款样音峰值分别为0.355133、0.349060、0.308655，RMS为0.121124、0.111381、0.127530；相邻采样最大差值为0.044525、0.064087、0.039703，首尾近零、无数字削波，不等于主观听感或实车无爆音证明。
