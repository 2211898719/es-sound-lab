# ICC车速核实边界（0.3.29）

2026-11-01用户实车反馈：VehicleConditionRsp字段2的原始整数就是本车km/h，车辆静止时可能省略该字段。0.3.29采用原值×1，不再显示0.3.28的四种候选；这是本车实测结论，不推广为全部车型的接口保证。

## 当前规则

- 仅接收ICC VehicleCondition白名单字段2，保存原始报文值。
- 显式非负整数直接显示为km/h；负数或无效值不解释为速度。
- 仅当本次查询成功且同一回复有已知挡位1/2/3/4时，车速字段省略按本车静止0处理；`sample.raw`仍为`MISSING`，并显示“本车静止时省略字段”。
- 无回复、请求失败、无效报文、挡位未知且省略车速都不会补0。停止、断开或回复接收/处理时间超5秒时不作为当前速度显示。
- 单位确认不等于及时性确认。5秒新鲜度只约束本地回复，当前没有车辆源时间戳，不能证明上游无缓存或保证端到端延迟。

诊断仍使用兼容字段名`iccSpeedComparison`，现在记录`confirmed=true`、`confirmation=user-verified-this-vehicle`、`unit=km/h`、`scale=1`、`raw`、`kmh`、`omittedZero`、`freshReply`、本地回复及处理时间、`automaticAudio=false`。历史数值可导出，但`freshReply=false`不得当成实时车速。

## 尚未启用的功能

车速仍不驱动模拟声浪或低速行人自动循环音。模拟声浪保持“敬请期待”，原有音源和设置保留。AutoHold另走授权日志，默认1=释放保持、2=正在保持，不用它推导P挡、车速或可行驶状态。

若继续测试延迟，由乘客记录正常行程自然出现的多个速度和起停片段，驾驶员不操作本应用、不为测试达到指定车速。结束后安全驻车导出，不要用本应用替代仪表或安全系统。自动低速音需后续单独实现阈值、防抖/迟滞、挡位限制及失效停音，不能仅凭单位核对直接开启。
