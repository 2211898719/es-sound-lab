# 车速拟合模拟声浪（0.3.34）

## 新增多层合成模式

详情上方打开“使用多层合成”，选择“V8 · 低沉巡航 / V10 · 高转运动 / 未来 · 电感涡流”。这里只切换渲染模式，不会打开自动声浪。升级默认保留原循环模式，关闭多层合成即可返回原音源；自选音频、曲线和主音量不覆盖。V8/V10有虚拟六挡、升挡卸载与降挡补油，未来音色连续变调。声调75–125%、力度0–100%、换挡运动倾向0–100%独立保存；改动时先停止当前视听。

七层为怠速及低/中/高转的驱动/收油，不是七段网站录音；全部由本项目独立生成。合成模式音高由虚拟动力模型生成，原音高曲线只影响循环模式，音量和加速增强曲线仍作用于两种模式。文件替换只改变循环模式音源，不会把一段录音自动变成多层音色。合成的5秒试听包含60ms起音、160ms收尾和100ms静音尾巴；连续行车播放不每圈淡出。

先在安全驻车时“开始 / 重置视听”，拖动虚拟油门观察虚拟挡位、RPM、换挡及收油，再按需开启“启用车速拟合声浪”。实车没有油门或发动机转速测量，负载由ICC车速/加速度及用户设置的马力/零百近似估计。所有ICC新鲜度、D挡、焦点和停止保护保持不变。实现、边界及诊断字段见[多层合成说明](multilayer-engine-sound-20261102.md)。以下音源和原音高曲线说明针对保留的循环模式。

## 使用入口

首页点击“模拟声浪”卡片或“选择预设 / 曲线详情”。可以先选择“舒适巡航 / 运动响应 / 电感平顺”，再点击“应用预设”。预设改变响应曲线，不改变音源；应用预设会覆盖当前自定义曲线。

详情页可以选择内置音频，或从文件/U盘导入并替换。单文件上限20 MiB，声浪要求≤30秒、单/双声道、8–96kHz；导入会先验证PCM解码，失败保留原音源，成功复制后不依赖U盘。建议使用稳定、无语音的循环WAV。0.3.33声浪不再用MediaPlayer循环，加载为PCM后在独立线程连续渲染，并对接缝交叉淡化；其他短提示音播放器不变。默认素材改为CC0赛车循环，授权、复现脚本及播放器细节见[PCM说明](pcm-engine-audio-20261102.md)。既有私有音源和曲线不覆盖；旧私有素材超过新解码上限时会安全失败，需选择较短循环。替换音频、应用预设和微调曲线都不会自行打开自动声浪。

“原音试听”播放素材本身、最多5秒，加入25ms起音、80ms收尾及100ms静音尾巴后排空输出再释放；这不等于给持续循环每圈淡出。它不模拟行车曲线，不要求D挡或启用自动声浪。自动播放默认关闭，使用独立的`engine.simulation.enabled`开关，旧版隐藏功能保存的`enabled.engine`不会在升级时自动打开它；既有音源和总音量保留。手动停止播放后自动声浪保持暂停，需关闭再启用声浪恢复。

## 动态视听 / 虚拟油门

模拟声浪不再标记为实验功能，仍默认关闭。首页去掉普通音频输出、查看实车信号快捷按钮和紧随的说明；车辆检测保留底部导航，普通输出设置移入声浪详情。

详情中“动态视听 · 虚拟油门”提供180匹/9秒、**280匹/7秒（默认）**、400匹/4.5秒、600匹/3.2秒预设，以及80–800匹、3.0–18.0秒自定义滑块。应用车型只改演示参数，不覆盖响应曲线、音源或音量。参数本地保存；修改车型会停止当前演示，点击开始可重置车速。

点击“开始 / 重置视听”，拖动0–100%虚拟油门。仪表和动态路面展示虚拟车速，另有加速度、模拟负载、音高及曲线音量×总音量显示；收油滑行减速。循环模式播放当前选择的音频，使用当前三条曲线和响应平滑；总音量与曲线编辑实时生效。合成模式则用独立虚拟动力模型生成转速、负载和换挡，同时保留音量/增强曲线。仅凭马力/零百不能重现某款发动机的真实频谱或动力。

数值模型仅用于调音，不推算真实车辆质量/扭矩/油门：`k = 20 × sqrt(hp / 280)`（m/s），`V = 100 / 3.6`，`A = (V + V³ / (3k²)) / 零百秒数`；`dv/dt = 油门 × A / (1 + (v/k)²) - (1-油门) × (0.3 + 0.0005v²)`。以≤10ms小步积分，保证理想全油门0–100接近设置时间；马力决定高速加速度衰减形状。没有坡度、质量、风阻测量或变速箱建模，两项参数不足以还原真实动力。虚拟速度与加速度按当前响应时间平滑后输入同一音高/音量/增强曲线，再平滑音频目标，与实车的曲线公式一致，但不虚构ICC采样延迟。

演示与真实ICC状态、导出读数和自动开关完全分离，不写入`states`或假冒真实油门；导出位于`engineSimulation.demo`且标记`virtual=true`、`actualPowerMeasurement=false`。单次最多60秒、最高200km/h；页面每100ms提供心跳，超过750ms无心跳或数值积分间隔>500ms即停止。离页、切后台、手动停止、校准、喊话、焦点丢失/播放失败、服务销毁或新鲜ICC非P挡/速度>1km/h停止演示，不自动重试。离线也可调音，不要求伪造P挡；驾驶员不得行车操作。演示不改变自动声浪开关；退出后自动声浪只可按新鲜实车样本重新积累，不沿用虚拟速度。

## 曲线编辑

三条曲线都在固定横轴锚点间线性插值，滑块编辑对应纵轴值；松手或拖动修改自动保存为“自定义”，旋转和重开页面保留参数。

| 曲线 | 横轴锚点 | 可调纵轴 |
| --- | --- | --- |
| 车速→音高 | 0、20、40、60、90、120 km/h | 0.50–2.00倍 |
| 车速→音量 | 同上 | 0–100% |
| 加速→增强 | 0、0.5、1、2、3 m/s² | 0–100% |

超出末点保持末值。加速增强只输入非负加速度；预设零加速度增强为0，减速不会取绝对值冒充加速。用户若将零点增强调高，匀速及减速也会带这个基础增强。

运行目标为：`load = 加速增强曲线(max(0, a))`；`pitch = min(2, 车速音高曲线(v) + 0.12 × load)`；`gain = clamp(车速音量曲线(v) + 0.5 × load × (1 - 车速音量曲线(v)), 0, 1)`。最后再乘独立声浪总音量，不写系统媒体音量或其他应用音量。PCM内核每采样平滑相位步进、增益和负载，并混合原始/低通音色；负载不是实测油门。虚拟RPM定义为`pitch × 3000`，只是控制量，内置素材没有可信的原始录制RPM。不是原厂发动机/电机模型，也没有虚构多转速实录音源。

响应平滑时间可在200–2000ms调整。三个预设分别为800/450/1000ms；这不是ICC轮询间隔，也不是端到端延迟保证。

## 采样与保护

- 仅使用当前ICC实际返回的非缺失车速原值（本车已核对单位km/h），不使用日志或旧探针补位。
- 实际采样间隔用`elapsedRealtime`计算，约1.5秒滑动窗口以线性回归估算加速度，再低通平滑；不按配置轮询间隔硬算。车速范围0–240km/h，异常跳变超过40km/h/s重新建基线，加速度限幅±6m/s²、小于0.08m/s²的斜率视为0，最多保留32点。
- 至少两个有效样本、跨度≥200ms后才允许播放。有效D挡、车速均要求近2.5秒；速度需原值和平滑值都大于1km/h。内部标准化D挡值为4，和ICC原始D=3不混用。
- 非D挡、无效挡位、停止监听、ICC重置、车速缺失/过期、校准、喊话、用户停止及功能关闭均停止声浪。即使本车ICC省略车速时状态大屏按约定显示0，缺失字段也不送入导数，避免把缺失当成急减速。重新可用时需要积累新样本；不跨断连或换挡计算加速度。
- 播放参数每100ms朝目标平滑变化，数据中断等失效条件立即停止，而非继续淡出旧状态。运行中修改曲线重建拟合基线；更换音源释放旧循环。
- 使用普通输出选择与媒体用途/持续音频焦点；不自动套用锁车usage2007/BUS、不写原厂ASD或AVAS。未获得焦点、播放器或参数失败时不强播，当前有效行车段不每100ms重复请求；可在安全驻车时重新启用或更换音源排查。系统接管焦点时停止，不与导航/电话争抢；系统释放后是否有恢复通知受音频策略影响。
- 短提示音会中断循环；短音效完成后只有当前仍满足新鲜数据条件才恢复。不新增唤醒锁或权限，不阻止车辆休眠。

## 展示与导出

详情页显示原始/平滑车速、估算加速度、模拟负载、目标音高与目标音量，均标注估算，不冒充油门或真实功率。无可用样本显示“—”，不补0。目标参数不保证实际扬声器已经出声；音频焦点、系统路由、文件解码以及车机策略仍可能阻止播放。

检测JSON新增`engineSimulation`，包含启用状态、完整曲线、拟合读数、样本年龄、目标参数及保护策略。`estimating`仅表示估算条件成立，不表示播放器或物理扬声器已经成功。ICC没有车辆源时间戳，无法通过重复的相同数值判断底层缓存是否新鲜；本方案是基于收到回复的近似音效，不是动力输出测量。

先在安全驻车时选音源、低音量试听和设置；需要行车对照时由乘员观察，驾驶员不操作界面。只启用声浪不自动申请系统日志。真实听感、车辆端参数支持、轮询时延及循环接缝仍需实车验收。
